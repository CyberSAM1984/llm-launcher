# LLM Launcher

Веб-панель для управления локальными моделями llama.cpp. Один Python-файл, только стандартная библиотека.

## Возможности

- Сканирует `start-*.bat` в папке llama.cpp, парсит `--alias`, `-m`, `-c`
- Запуск/остановка/переключение моделей одним кликом
- Статус-бар: скорость генерации (tok/s), VRAM, GPU utilization (обновление каждые 2 сек)
- Замер скорости через нативный `/completion` endpoint
- Проверка ответа модели через `/v1/chat/completions`
- Таблица процессов, потребляющих VRAM
- Лог llama-server
- 5 альтернативных тем оформления (`/themes`)

## Запуск

```
pyw -3 launcher.py
```

Панель доступна на `http://localhost:8090`.

С флагом `--open-browser` откроет браузер автоматически.

## Требования

- Windows (пути настроены на `E:\Ai\llama.cpp`)
- Python 3.x (только stdlib, без зависимостей)
- llama-server с флагом `--metrics`

## Файлы

| Файл | Назначение |
|------|-----------|
| `launcher.py` | Основной сервер панели (порт 8090) |
| `themes/` | Альтернативные темы оформления |
| `LLM Launcher.bat` | Запуск с открытием браузера |
| `LLM Launcher.vbs` | Автозапуск при входе в Windows (без окна) |
